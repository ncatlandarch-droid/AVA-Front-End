Gaussian Splatting Guide for Maria

Photorealistic Digital Twin — Step-by-Step Playbook
Prepared by W. Chris Harrison · June 28, 2026

What Is This?

We're turning your LiDAR scan into a photorealistic 3D walkthrough that anyone can view in their browser. Gaussian Splatting takes your existing point cloud + new photos and creates a scene that looks like a real photograph from every angle.

End result: A QR code anyone can scan to walk through the courtyard in 3D on their phone.

This doesn't replace your Revit/Rhino segmentation work — it's the visualization layer alongside the engineering model. Two parallel tracks.

1
Take Photos of the Courtyard 📱
~30 minutes of fieldwork

Go to the Inspiration Courtyard with your phone and take 150–200 photos.

How to Walk It

  • Walk the full perimeter — photo every 3–4 steps
  • Walk through the interior in a grid/zigzag pattern
  • Get every wall, bench, planter, tree from 2–3 angles
  • Include shots looking up (canopy) and down (pavement)

Camera Tips

  • Hold phone steady — no motion blur
  • Each photo should share ~70% overlap with the previous one
  • Avoid direct sun glare · Overcast days work best
lightbulbSave all photos in one folder: courtyard_photos
2

Generate the Gaussian Splat 🧠
~1 hour (computer does it)

Follow whichever path matches what worked in Step 2:

✅ PATH A — Pix4D / DJI Terra Did Everything

If Pix4D or DJI Terra already generated a .ply Gaussian Splat file → you're done with this step! Skip to Step 4 (cleanup).

🔄 PATH B — Using COLMAP + Nerfstudio

First, run COLMAP (has a graphical interface — no command line!):

  1. Open COLMAP
  2. File → New Project → point to your courtyard_photos folder
  3. Processing → Feature Extraction → click Extract → ☕ wait ~10 min
  4. Processing → Feature Matching → Exhaustive → ☕ wait ~15 min
  5. Processing → Start Reconstruction → ☕ wait ~15 min
  6. File → Export Model → save to courtyard_sparse

✅ You should see a point cloud that looks like the courtyard
✅ Status bar shows most photos registered (e.g., "190/200")

Then, train the Gaussian Splat:

# Prepare the data
ns-process-data images --data ./courtyard_photos --output-dir ./courtyard_processed

# Train! (the magic step)
ns-train splatfacto --data ./courtyard_processed
  • A viewer opens in your browser at localhost:7007
  • Watch the courtyard form — blurry at first, then photorealistic
  • Takes 30–60 min · Don't close the terminal!
  • When done: check outputs folder for the .ply file

GPU Check (for Path B only)

# Type this in Command Prompt:
nvidia-smi

  2. Drag & drop your .ply file
  3. Delete floating junk · Crop to courtyard area
  4. Export → save cleaned .ply
